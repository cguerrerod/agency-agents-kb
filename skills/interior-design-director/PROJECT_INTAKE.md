# Residential Project Intake Protocol

This protocol tells the user how to document a house progressively without needing a professional survey.

## Goal
Create a coherent spatial model of the property from the minimum useful evidence.

## Recommended sequence

### 1. Whole-house orientation
Provide:
- number of floors;
- approximate overall footprint if known;
- front/entrance location;
- any existing floor plan, even hand-drawn;
- north/orientation if known.

### 2. Room-by-room photo capture
For each room:
1. Stand near the doorway and photograph inward.
2. Photograph back toward the doorway.
3. Photograph each remaining wall/corner.
4. Include ceiling and floor boundaries when possible.
5. Capture connections to adjacent rooms.
6. Avoid extreme digital zoom.
7. If possible, keep camera roughly level.

For corridors, capture both directions and every intersection.

### 3. Critical dimensions
Do not measure everything initially. Prioritize:
- room length × width;
- ceiling height;
- door opening width/height;
- window width/height and sill height;
- wall segments where furniture may go;
- major fixed furniture/built-ins;
- furniture that must be retained.

### 4. Evidence anchors
Helpful scale references:
- a measured door;
- a measured tile;
- a measured wall segment;
- known furniture dimensions.

Never use a generic object (e.g. “standard door”) as exact scale unless actually measured.

### 5. Household brief
Capture:
- who uses the room;
- typical activities;
- storage needs;
- items that must stay;
- items that may go;
- desired style;
- budget level;
- maintenance tolerance;
- special constraints (children, pets, heat, humidity, accessibility).

## Minimum evidence by task

### Quick decoration advice
- 2–4 photos;
- approximate dimensions;
- what must stay;
- style objective.

### Furniture layout
- room dimensions;
- doors/windows;
- furniture dimensions;
- 4-direction photo set.

### Whole-room redesign
- full photo set;
- room dimensions;
- ceiling height;
- adjacent spaces;
- lighting/openings;
- use case.

### Architectural change
- dimensioned plan if available;
- clear wall/opening photos;
- construction/structural documentation when available;
- professional validation if structure, utilities or code are affected.

## Interaction rule
Ask only for evidence that is likely to change the design decision. Avoid overwhelming the user with survey requirements before giving useful advice.
